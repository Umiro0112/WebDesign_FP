# WebDesign_FP

An exploration-based language-learning website for a web design final project.

The project will let learners explore a shared neighborhood, choose the situations they want to practice, and collect useful expressions in one of five target languages.

## Current status

Phase 4 is complete: the restaurant now has a responsive interior scene and a complete three-part conversation in Japanese, Spanish, French, German, and Chinese. Learners receive feedback, can switch a typing challenge to choices, and can save useful phrases to a persistent review bag.

## Run locally

Open `index.html` in a browser, or serve the repository with any local static server.
